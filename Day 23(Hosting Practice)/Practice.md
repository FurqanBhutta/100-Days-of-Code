# Day 23 - Hosting a Node.js App on Ubuntu (VirtualBox)

## 📌 Overview
On Day 23 of my #100DaysOfCode challenge, I practiced deploying a simple Node.js application on an Ubuntu virtual machine running inside VirtualBox.

Instead of running the application directly on Windows, I used Ubuntu as a Linux server and accessed it remotely using SSH.

## 🎯 What I Learned

- Setting up Ubuntu in VirtualBox
- Connecting to the Ubuntu server using SSH from Windows Command Prompt
- Basic Linux terminal commands
- Editing files using Vim
- Running a Node.js application on Ubuntu
- Accessing the application through the server's IP address and port

## 🛠️ Technologies Used

- Node.js
- Ubuntu
- VirtualBox
- SSH
- Vim
- Windows Command Prompt

## 📂 Project Workflow

1. Start the Ubuntu virtual machine.
2. Connect to Ubuntu using SSH from Windows CMD.
3. Create/edit the Node.js application using Vim.
4. Save the file and exit Vim.
5. Run the application using Node.js.
6. Open the browser and visit:

```
http://<Ubuntu-IP-Address>:<Port>
```

Example:

```
http://192.168.100.146:3000
```

## 📸 Output

The application was successfully served from the Ubuntu virtual machine and accessed through the browser using its IP address and port.

## 💡 Key Takeaways

- Learned the basics of Linux server management.
- Understood how SSH enables remote server access.
- Practiced editing files with Vim.
- Gained hands-on experience hosting a Node.js application on Ubuntu.
- Improved my understanding of networking using IP addresses and ports.
